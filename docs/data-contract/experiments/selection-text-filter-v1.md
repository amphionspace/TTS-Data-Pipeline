# Selection 文本过滤实验契约

状态：实验设计。规则版本 `selection-text-filter-v1`，基础 `contract_version=v0.1` 不变。
本稿记录已经确定的文本过滤策略，不表示执行器、阈值或全库过滤结果已经验收。
适用于所有数据集；实际运行只消费固定的已发布输入，不因本稿自动启动筛选或重新转写。

## 职责与范围

继承 [annotation](../specs/05-annotations.md)、[selection](../specs/12-selections.md)
和 [文本特征](../specs/13-text-features.md) 的身份、依赖、文本采用及发布约定。
annotation 保存原始测量和执行结果，selection 计算过滤决定及证据。
排除只表示不进入本版训练集合，不删除基础样本，不改写 annotation 文本或将其状态改成 failed。

本稿包括纯文本检查及使用实际完整音频时长的音文长度比检查。
解码、全零、非有限值、音量、削波、DNSMOS 等条件属于独立音频规则，不在本稿定义阈值。
语言允许集合属于 selection 的独立条件；ASR 与独立语言识别的一致性不属于全库通用文本规则。

## 固定文本与语言来源

每个输入范围必须先确定最终选用文本、选用语言、实际音频范围及其固定版本。
所有文本检查、长度比、重复组裁决和训练读取使用同一份选用结果。

- 默认使用 samples 的基础文本和语言，不要求所有数据重新执行 ASR。
- 明确采用新转写的范围引用固定 annotation manifest、表快照及输入基础版本，不读取 latest。
  主转写为采用对象；指定语言生成的候选不自动替换主转写，也不作为独立语言识别证据。
- 所要求的 annotation 缺失、failed、unsupported 或 skipped 均不能作为有效替换，记录具体状态并排除。
  成功但转写为空也排除；不隐式回退到基础字幕。来源身份或版本发生系统性冲突时停止阶段排查。
- 不覆盖基础语言。语言采用方式、别名映射、允许集合在 selection 中显式固定；
  不用 ASR adapter 的 accepts(language) 代替训练允许语言集合。

当前采用计划：

| 范围 | 文本来源计划 |
| --- | --- |
| 原神、星铁、鸣潮、绝区零 | 采用本轮已发布 ASR 的主转写；运行前固定准确 run 与输入版本 |
| Emilia2 | 复用上游 short 文本；用户确认其由 Qwen ASR 1.7B 生成，不安排重复转写；尚未发布时不加入运行 |
| 其余来源，包括 Emilia、Emilia-YODAS、HiFiTTS 系列和 Galgame | 保留基础文本，执行相同通用规则；不安排全量重跑 ASR |

以上是本轮文本来源选择，不构成对某个数据集准确率的保证，也不设置数据集专用过滤阈值。
上游模型名称来自用户确认时保留这一来源，不据此补造精确权重版本或推理参数。

## 选用文本与分析文本

选用文本沿用正式 05 的来源记录、text_revision 和稀疏覆盖约定，只做首尾去空白。
不改内部空白、标点、大小写，不自动删除重复内容或补写缺失文字。

分析副本采用以下固定口径，不回写训练文本：

1. 使用 Unicode NFC 归一化。
2. 有效字符为 Unicode General Category 的 L（字母）或 N（数字），按 code point 计数；
   汉字、假名、韩文等包括在内，空白、标点、纯符号和独立组合标记不计入。
3. 长度比使用上述字符数，不使用字节数、ASR token 数或词数。
4. 复读匹配另做 Unicode casefold，随后 NFC；保留词边界，不能先删除空白再做词级分析。
   分词实现、字符提取方式、Unicode/运行库版本在试验实现中固定并记录，不依赖未记录的默认配置。

最低有效字符数统一为 1，允许“嗯”“好”“啊”等短应答。
不因来源为 short、long 或 dialogue 设置不同下限；已有音频时长策略仍独立生效。

## 通用文本规则

| 逻辑原因 | 判定 | 处理 |
| --- | --- | --- |
| text_source_unavailable | 配置要求的 annotation 缺失或状态不可用 | 排除，保存缺失/失败/不支持/跳过的具体原因 |
| empty_text | 选用文本缺失、为空或有效字符数为 0 | 排除，不计算除法 |
| invalid_transcript | 存在明确输出截断证据，或解析后残留已知模型协议标记 | 排除；系统性解析问题停止发布并排查 |
| text_repetition | 同一 n-gram 的次数和全文覆盖率同时达到下述门槛 | 排除整条，不裁剪文本 |
| text_too_dense | 完整音频秒数/有效字符数低于对应语言下限 | 排除 |
| text_too_sparse | 完整音频秒数/有效字符数高于对应语言上限 | 排除 |

协议标记检查使用对应来源明确的控制标记集合，不把任意尖括号或括号文本当作协议错误。
没有句号、句子不完整不是截断证据。ASR 原已 failed 的目标保留原状态，由 selection 记录来源不可用。
本表的名称是实验逻辑原因，不是已注册的生产数字码；实现前须按正式 12 扩展原因及 flag 字典，
不得复用现有码改变含义，也不能把策略排除标成 confirmed_mismatch。

## 复读检查

采用 Emilia2 参考方案的长度、重复次数和覆盖率门槛：

| 路径 | 启用条件 | 单元 |
| --- | --- | --- |
| 词级 | 语言适用词级分析，且至少 18 个词 | 4-gram |
| 字符级 | 不适用词级或词数不足，且至少 30 个有效字符 | 8-gram |

实现前固定适用词级分析的语言与分词规则；无空格语言不能把整句当成一个词。
词级路径适用时采用词级检查，否则采用字符级；两者的最低长度都不满足时，记录复读未检查，其他规则继续。

对每个不同 n-gram，按不同起点统计出现次数，允许匹配区间重叠；满足以下两项才排除：

```text
出现次数 >= 5
该 n-gram 所有出现区间的并集长度 / 整条分析序列长度 >= 0.80
```

词级分子分母均为词数，字符级均为有效字符数；重叠位置只计一次。
不同 n-gram 的覆盖率不能相加凑阈值。检查单条完整选用文本，不跨样本累计，也不以局部小窗口命中代替全文覆盖率。
记录触发单元、次数和覆盖率。命中表示本策略认为重复过高，不等同于已听检确认 ASR 幻觉。
不额外增加压缩率硬门槛，不使用人名、拟声词或常见句子黑名单。

## 音文长度比

```text
audio_seconds_per_character = audio_seconds / effective_character_count
audio_seconds = 当前选用音频范围实际采样点数 / 对应原生采样率
```

当前整条 sample 使用完整实际音频范围；将来若显式选用片段，必须绑定该片段及对应文本重新计算。
音频时长可复用范围匹配的 audio_stats 或 ASR 实际输入时间轴证据，必须核对音频身份与范围。
仅有头信息或上游 duration 时，不能冒充实际解码时长；缺少可信时长记录为未检查，
本版要求的长度检查未完成时不能发布为已通过，须补齐证据或明确排除。既有头信息小差异不另作坏样本理由。

| 选用语言 | 保留范围，秒/有效字符，包含边界 |
| --- | --- |
| 中文、粤语、日语、韩语、泰语（zh、yue、ja、ko、th） | 0.04–2.0 |
| 其他已允许语言 | 0.015–1.0 |

上下限均为硬过滤：低于下限排除 text_too_dense，高于上限排除 text_too_sparse，等于边界通过。
该表不自动扩大 selection 的允许语言集合；语言未知按独立语言条件处理，不猜测阈值组。
使用完整音频时长，不估计有效语音时长，不扣除低能量区间或首尾停顿；不新增语音检测依赖。
包含长停顿但文本很少的样本也按上限排除，这是已经选定的数据策略，不声称文本一定错误。
正有限时长、正采样率及有效范围由输入检查保证；非法时间轴不能静默当作长度检查通过。

| 示例 | 比值 | 长度检查结果 |
| --- | --- | --- |
| 中文 1 秒、100 字 | 0.01 | text_too_dense |
| 中文 10 秒、2 字 | 5.0 | text_too_sparse |
| 中文 1 秒、1 字 | 1.0 | 通过 |
| 英文 10 秒、100 个有效字符 | 0.1 | 通过 |

## 四个游戏的额外语言一致性实验

范围仅为 genshin_voice、starrail_voice、wutheringwaves、zenless_voice；不属于上述通用文本硬过滤。
独立语言识别另按 [annotation 实验](annotation-v1.md) 验证，暂不因本稿启动模型运行。

- 比较固定主 ASR 的语言与独立 LID 的语言，保留来源语言、ASR、LID 三类证据。
- 语言别名规范化后不一致可以记录 language_conflict，但不自动硬排除或覆盖标签。
- 短应答、喊声、笑声和拟声等需在小测中检查误判；LID 原始分数不等于校准后的正确概率。
- 可信门槛、缺失结果和冲突采用策略尚待验证，不能先写死“一不一致就删除”。
- 其他数据集即使补充 LID，也先记录与来源标签的差异，不因冲突自动排除。

基础语言是否允许仍按独立 selection 规则执行；不能与这里尚未启用的冲突过滤混淆。

## 证据、执行与发布

保留主排除原因及所有命中 flags，优先级显式固定。逻辑证据至少包括：

- 文本及语言来源、固定输入版本、text_revision、音频对象及范围。
- 有效字符数、词数、复读检查路径及已检查/不适用状态。
- 命中复读的单元、次数、覆盖率；采用的时长、时长证据来源、秒/字符比。
- 规则版本、阈值、分析和分词实现版本；逐条原因与分组统计。

物理字段布局在实现时沿用 selection 约定确定，不为这些轻量计算新增 annotation 模型任务。
过滤不需要逐条人工审核，规则通过也不宣称文字已经完全准确。

```text
固定输入 → 选择文本/语言/音频范围 → 通用文本过滤
→ 组合独立音频与其他选择条件 → 按最终文本和语言重新裁决重复组
→ 回读校验 → 发布新的 selection
```

先在 artifacts 验证实现与全库命中统计，再正式发布；按数据集、语言和文本长度统计每项原因、
原因交集及最终保留率，区分尚未检查与通过。不仅抽取异常样本，也保留随机对照，检查是否集中误删某类正常数据。
空文本、单字应答、Unicode 计数、复读重叠区间、长度阈值边界及来源失败不得回退等行为需要实现验收。
不覆盖已有 selection 或 features；文本变化后下游 text/merged 元数据绑定遵守正式契约。

当前 selection 执行器仍需补齐固定 annotation 文本采用及后续 selection 发布，本文不会改变现有运行配置。

## 参考及取舍

- 用户提供的 Emilia2-pipe 规则说明：参考其 4/8-gram、18/30 最低长度、5 次、80% 和秒/字符范围。
  未读取用户本地源码；本稿定义本仓库的实验语义，不声称逐行复刻原实现。
  与参考不同的是全库统一最低 1 个有效字符，并统一使用实际完整音频时长。
- [NeMo SDP 字符速率过滤](https://nvidia.github.io/NeMo-speech-data-processor/sdp/adding_processors.html)：
  参考文本量与时长的检查方式，阈值采用本稿约定。
- [NeMo Curator 重复检查](https://docs.nvidia.com/nemo/curator/latest/curate-text/process-data/quality-assessment/heuristic)：
  参考 n-gram 检测与先统计再过滤的流程，不套用通用文档长度及重复阈值。
- [Whisper 解码检查](https://github.com/openai/whisper/blob/main/whisper/transcribe.py)：
  压缩率属于解码回退信号，本版不将其单独作为已完成转写的硬排除条件。
