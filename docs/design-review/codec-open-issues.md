## 问题二：固定 padding/batch 的可重复性不是独立参考等价性

已知机制包括两层：无效区域可能通过卷积/下采样边界影响有效输出；计算形状变化可能引入浮点差异，
经最近邻量化后变成不同码字。FP16、attention 语义、码本缓存初始化也会影响结果，不能全部归因于 padding。

C 已有逐层有效长度、有效末尾 replicate、全因果 FA2 和固定 bucket/batch 的处理。
这些实现与现有测试是有效证据，但当前路径仍然分桶补齐：尾批也补足槽位，padding 仍有计算成本。
尤其 `Encoder.encode_single()` 实际调用 `encode_many([wave])`，仍进入 canonical padded batch，
所以现有“单条一致”不能当成独立的、真正不补齐的单条参考实现对照。

已证实的范围：398 条真实输入加 14 条边界样本，每卡 412 条；换序、邻居、槽位、尾批和八卡码字一致。
另有三份小数据集的并发配置端到端对照，以及六条用户接受的试听样本。
这些说明固定 C 规则下的复现性和局部可接受性，未单独证明有效边界与独立参考一致，也不证明所有输入的音质。

补验要求：

1. 建立真正单条、无批次补齐的独立参考，固定同一权重、前处理、FP16/FP32 使用位置、attention 语义和码本缓存。
   不将已退役 FP32 A/B 与 C 的天然精度差异误记为 padding bug，也不要求不同 profile 无条件逐码字一致。
2. 分阶段比较卷积有效输出、attention、下采样和量化输入/结果，定位内容边界变化与浮点形状误差。
3. 覆盖 2 秒桶边界、各层 stride/hop 余数、短长混批、尾批、槽位与并发；保留差异位置、幅度和逐码本统计。
4. 若码字不同，继续检查重建边界与音质，不用“可重复”代替正确性，也不用“码字不同”直接判定音质失败。
5. 明确最终承诺：与参考等价，或有独立质量验收的数值变体。改变数值路径需新 profile 和重新验收。
   padding-free 只是一种候选；更换变长 attention 接口不能自动解决卷积边界与量化形状问题。
